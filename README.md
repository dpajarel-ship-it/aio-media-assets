# AIO Media Assets

Repositorio público del ecosistema **AIO Media Ecosystem** destinado a almacenar los recursos gráficos necesarios para el proyecto, disponibles para su consumo directo mediante URLs públicas de GitHub.

## Estructura de carpetas

- **`logos/`**: Identidad visual y logotipos clasificados por proyecto:
  - `aio-media-ecosystem/`: Identidad visual y logotipo principal (`aio-media-ecosystem.png`).
  - `aiometadata/`: Recursos gráficos y logotipos de AIO-Metadata.
  - `aiostreams/`: Recursos gráficos y logotipos de AIOStreams.
  - `nuvio/`: Recursos gráficos y logotipos de Nuvio.
- **`avatares/`**: Imágenes de perfil optimizadas en formato WebP (512 × 512 px) para los perfiles de AIOStreams (`antonio.webp`, `david.webp`, `jesus.webp`, `pablo.webp`, `victor.webp`).
- **`nuvio-collections/`**: Recursos visuales oficiales para colecciones de plataformas en Nuvio / AIOStreams (7 servicios con `cover`, `focus`, `backdrop` y `logo`), documentados en [su propio README](nuvio-collections/README.md) y [manifest.json](nuvio-collections/manifest.json).
- **`plataformas/`**: Logos e imágenes de plataformas de streaming (ej. Netflix, Disney+, Prime Video, etc.).
- **`fondos/`**: Fondos de pantalla, carátulas panorámicas y backdrops.
- **`iconos/`**: Iconografía auxiliar para menús, categorías y formatos.
- **`otros/`**: Recursos gráficos complementarios o sin clasificación específica.
