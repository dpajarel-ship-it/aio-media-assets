## 1. Servicios Incluidos

- **Netflix** (`nuvio-collections/netflix/`)
- **Prime Video** (`nuvio-collections/prime-video/`)
- **HBO Max** (`nuvio-collections/hbo-max/`)

- **SkyShowtime** (`nuvio-collections/skyshowtime/`)
